# Lumen – Apple-style website (React + CSS + Vite)

## Run
```bash
npm install
npm run dev      # development  -> http://localhost:5173
npm run build    # production build -> dist/
npm run preview  # preview the build
```

## Edit content
- Menu, product text and footer links: `src/data.js`
- Colors, fonts, spacing: top of `src/App.css` (CSS variables)
- Product drawings (pure CSS, no images): `src/components/Visuals.jsx`

"Lumen" is a fictional brand, so no Apple logos or images are used.
Replace the CSS visuals with your own `<img>` tags when you have product photos.
